## 二、如何在飞书添加标签选项

### 方法：编辑「标签」字段

1. **打开多维表格**，找到「标签」列

2. **点击列标题**「标签」旁边的下拉箭头 ▼

3. 选择 **「编辑字段」** 或 **「字段设置」**

4. 在弹出的设置面板中，点击 **「添加选项」**

5. **逐个输入**上面的 15 个标签：
   - 输入标签名称（例如：`RAG`）
   - 选择颜色（可选，方便区分）
   - 点击"确定"或回车
   - 继续添加下一个

6. 全部添加完成后，点击 **「保存」** 或 **「完成」**

## 三、日常使用：添加新标签

### 场景
运行 `podcast_brief` 后，终端会显示本次使用的所有标签：

```bash
本次播客标签 (8 个):
  Agent, Fine-tuning, OpenAI, RAG, 企业服务, 产品增长, 可解释性, 投资策略

提示: 如果某些标签未在飞书表格中显示，
  请在飞书「标签」字段设置中添加对应选项
```

### 如何处理新标签

#### **情况 1：新标签是常见/高频的**
例如：`可解释性` 在多集播客中出现

**操作**：
1. 在飞书「标签」字段设置中添加 `可解释性` 选项
2. 下次运行时，这个标签就会自动显示在表格中

#### **情况 2：新标签是低频/一次性的**
例如：某集播客提到 `区块链`，但其他播客都不涉及

**操作**：
- 可以不添加到字段选项
- 或者添加后备用（以后可能会再次出现）

## 四、标签管理策略

### **推荐做法**（每周维护 5 分钟）

1. **每周查看一次终端日志**，记录新出现的标签

2. **筛选高频标签**：
   - 如果某个标签在 3+ 集播客中出现 → 添加到飞书
   - 如果某个标签只出现 1 次 → 暂时不添加

3. **分类管理**：
   - 技术类标签：偏向具体技术（如 `Transformer`、`RLHF`）
   - 产品类标签：偏向商业/增长（如 `用户留存`、`订阅模式`）
   - 公司类标签：主流公司/产品（如 `Anthropic`、`Claude`）

4. **定期清理**：
   - 如果某个标签 3 个月没再出现 → 可以考虑删除

## 六、优势 vs 限制

### ✅ **方案 1 的优势**

1. **保留飞书筛选功能**
   - 可以创建"RAG"视图 → 只显示包含 RAG 标签的播客
   - 可以按标签分组，看到每个领域的内容分布

2. **标签规范化**
   - 避免 LLM 输出不一致（如 `RAG` vs `检索增强生成`）
   - 保证标签命名统一

3. **灵活扩展**
   - 随时添加新标签，不需要改代码
   - 适应新技术/新趋势

### ⚠️ **需要注意**

1. **首次运行**：
   - 某些标签可能不会显示在飞书表格中
   - 这是**正常现象**，飞书多选字段只显示已配置的选项

2. **定期维护**：
   - 建议每周花 5 分钟检查新标签
   - 高频标签及时添加到字段选项

## 七、快速参考

### **添加新标签的 3 步**

1. **运行 podcast_brief** → 终端显示所有标签
2. **打开飞书表格** → 点击「标签」列标题 → 「编辑字段」
3. **添加新选项** → 输入标签名 → 选择颜色 → 保存

### **检查标签是否生效**

- 运行后打开飞书表格
- 查看「标签」列是否显示了标签
- 如果未显示，说明该标签还未添加到字段选项
